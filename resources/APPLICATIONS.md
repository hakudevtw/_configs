# App 清單

大部分 app 由 [Brewfile](../Brewfile) 安裝（個人專用、公司專用、選用分別在 `Brewfile.personal`、`Brewfile.work`、`Brewfile.optional`）；每個工具是什麼、怎麼用，看 [TOOLS.md](TOOLS.md)。

## 不在 Brewfile 裡的

- **[Google Antigravity](https://antigravity.google)**、**[Gemini app](https://gemini.google.com/app)**：沒有 Homebrew 套件，要自己下載。目前沒在用。
- **LINE**：在 Mac App Store，由 Brewfile 的 `mas` 安裝。要先登入 App Store。
- **公司管理的軟體**（Office、OneDrive、ESET、Defender）：由公司 IT 配發，不屬於這個 repo。

## Chrome 安裝的網頁 app

- **YouTube Music**：在 Chrome 開 music.youtube.com，用網址列右側的「安裝」變成獨立 app。它是 Chrome 的網頁 app，不是 Homebrew 套件，每台電腦要自己在 Chrome 裡安裝一次。
