# Apple 備忘錄使用規則

備忘錄在這套工具裡的角色：**快速收集箱**。先記下來，整理成長期知識後再搬到 Obsidian。工作內容放 Notion，不放這裡。

這份只寫規則，**不放任何筆記內容、帳號或密碼**。

## 原則

- **先記，不整理。** 所有新筆記都先進 Inbox，不用想放哪。
- **資料夾保持少。** 只留 4 個，多了就找不到。
- **敏感資料不放備忘錄。** 帳號、密碼、金鑰、證件號碼放 Bitwarden（規則見 [BITWARDEN.md](BITWARDEN.md)）。
- **長期知識不放備忘錄。** 值得留下來的，搬到 Obsidian。

## 資料夾

| 資料夾 | 放什麼 |
|---|---|
| 📥 Inbox | 所有新筆記的預設位置；手機上隨手記也進這裡 |
| 🛒 Lists | 會反覆勾選的清單：購物、待買、待看 |
| 📌 Reference | 短、常翻的小資料：地址、尺寸、型號 |
| 🗄️ Archive | 不用但不想刪的 |

帳號是 iCloud（免費方案），會跟 iPhone 同步。預設資料夾在 備忘錄 → 設定 裡指定為 Inbox。

## 怎麼用才有效率

| 做法 | 怎麼做 |
|---|---|
| 不開 app 就記 | Raycast 的 Apple Notes 擴充功能，直接輸入並存進 Inbox |
| 在任何 app 裡浮出一則備忘錄 | `Fn+Q`（地球儀鍵加 Q）的快速備忘錄 |
| 搜尋全部 | `Cmd+Option+F`，也搜得到附件和圖片裡的文字 |
| 標籤 | 內文打 `#標籤`，側邊欄自動出現；比資料夾輕 |
| 釘選 | 常翻的筆記釘在頂端 |
| 清單 | 用核取清單，完成的項目可設為自動沉到底部 |

## 每週 5 分鐘

清空 Inbox，每一篇三選一：

1. 值得留 → 搬到 Obsidian。
2. 短資料、常翻 → 移到 Reference 或 Lists。
3. 沒用了 → 刪除；不確定就放 Archive。
