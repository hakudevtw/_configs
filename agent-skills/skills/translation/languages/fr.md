# French (fr)

Native review: none yet.

## Register

Vous throughout. Instructions in the infinitive for lists of rules (Attacher sa ceinture) and imperative vous for direct requests (Indiquez-nous…), one style per list.

## Words and traps

- False friends and calques: complet means fully booked (a full-size coach is grand format); trajet simple reads as "easy trip" (one way is aller simple); atterrissage tardif → arrivée tard le soir; ce qui voyage avec le groupe → ce que le groupe emporte.
- Seats as capacity are places, not sièges.
- A site inspection is une visite de repérage.
- Politique alone as a label reads as politics: Conditions, Politique d'annulation.
- No English left (service trade → service dédié aux professionnels).

## Typography

- Sentence case for titles.
- Quotes « ». A narrow no-break space before : ; ! ? is correct; follow the product if it omits it, consistently.
- Times 8 h 00 or 8h00, one form; dates 9 octobre 2026; thousands with a space (1 000).

## Place names

Usual romanisation for landmarks; French forms for regions and features (les Alpes japonaises, l'étang Bleu de Shirogane).
